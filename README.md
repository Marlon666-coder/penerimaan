# Penerimaan Mahasiswa Baru (PMB) Online

Website statis sederhana untuk Penerimaan Mahasiswa Baru, dibuat dengan **HTML, CSS, dan JavaScript** (tanpa backend).

## Fitur
- Landing page responsif (beranda, alur pendaftaran, program studi)
- Formulir pendaftaran dengan validasi
- Data pendaftar disimpan sementara di `localStorage` browser (demo)

## Struktur
```
index.html   # Halaman utama
style.css    # Gaya tampilan
script.js    # Validasi form & interaksi
```

## Menjalankan Secara Lokal
Cukup buka `index.html` di browser, atau jalankan server statis:
```bash
python3 -m http.server 8000
# lalu buka http://localhost:8000
```

## Deploy
Website ini di-deploy menggunakan **GitHub Pages** dari branch `main`.
